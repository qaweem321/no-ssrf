Use it

import { checkUrl } from "no-ssrf";          // anywhere: Node, Bun, Deno, edge, browser
import { safeRequest } from "no-ssrf/node";  // Node: checks every DNS answer and redirect

const verdict = checkUrl(userUrl);
if (!verdict.ok) return { error: verdict.reason };

const res = await safeRequest(verdict.url, { method: "POST", body, timeoutMs: 5000 });

Checking the URL is half the job: a domain can resolve to a private address, or switch to one between your check and the request. safeRequest checks the address it actually connects to. Source, docs and tests on GitHub.
